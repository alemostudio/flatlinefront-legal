# Privacy Policy — ALEMO Studio Reference Tool (Pinterest)

Effective date: 2026-10-18

ALEMO Studio ("we") runs a small internal tool that reads Pinterest content through the official Pinterest API v5. This page explains what the tool accesses and how that data is handled.

## 1. What the tool is for

The tool lets our own team look at **our own Pinterest account's** boards and Pins as art reference for game graphics. It is not offered to the public and has no other users.

## 2. What data it accesses

- Basic account information of the connected account (username, account type) — to confirm the connection.
- Boards, board sections and Pins of the connected account, including Pin titles, descriptions and image URLs.
- Search over the connected account's own Pins.

The tool uses **read-only** scopes (`user_accounts:read`, `boards:read`, `pins:read`, and the matching `_secret` read scopes for the account's own secret boards). It never creates, edits or deletes boards or Pins, and it does not collect data about other Pinterest users.

## 3. How data is stored

- The access token is stored only on the team's own computer, outside any source repository, and is never shown or shared.
- Images saved for reference are kept on that computer only, used as inspiration (not copied or redistributed), and deleted when no longer needed.
- No analytics, advertising or tracking is used.

## 4. Sharing

We do not sell, rent or share any data obtained from Pinterest with third parties.

## 5. Your choices

The connected account owner can revoke the tool's access at any time in Pinterest settings (Security and logins → Apps). On request we delete the stored token and any saved images within 10 days.
